# Remaining path to a completed study

The portable software infrastructure is implemented. These are scientific and
integration milestones, not a claim that writing more code will produce a paper.

| Milestone | Evidence required to close it |
|---|---|
| Backend validation | Real small-system output parsed and independently cross-checked for each chosen engine/checkpoint |
| Teacher audit | Reproducer code/assets/state/settings reviewed; same-geometry pilot agrees within a predefined tolerance |
| Reference audit | Source values, corrections, method/state validity and uncertainty reviewed; questionable targets separated |
| First controlled pilot | A small batch of true MLIP/teacher/reference observables with raw output, hashes and failure report |
| Signal audit | Reference-blind prevalence, ordinary UQ behavior, cross-model sensitivity and label uncertainty characterized |
| Diagnostic pilot | Incremental out-of-sample signal from genuinely costed descriptors; negative findings retained |
| Protocol freeze | Independent grouping, overlaps, thresholds, model choices, baselines and costs documented before final test use |
| Held-out study | Frozen artifact, test predictions, eligible/raw denominators, group confidence intervals and cost–accuracy analysis |
| Independent chemistry case | Competing pathways evaluated with suitable states, frequencies/IRC as needed, and credible high-level calculations |
| Reproduction | A second clean environment regenerates outputs from versioned parsed data and configuration |
| Publication package | Methods, source/compute provenance, SI, limitations, archived data, collaborator review, and an appropriately scoped manuscript |

A negative result is a valid endpoint: rare reference-blind errors, diagnostic
failure, inadequate high-level references, or no benefit over simple screening
must not be hidden. Do not tune the chemistry cohort simply to force a result.
